Codex 私人端 - 员工独立版

每个人都是完全独立的：

- 使用自己的 Windows 电脑。
- 使用自己的 Codex/API 配置和 API Key。
- 使用自己的 Tailscale 账号连接自己的电脑和手机。
- 只能看到自己电脑上的任务和文件。
- 不需要加入任何管理员或公司共享网络。
- 本包不包含任何 API Key、账号密码或管理员网络地址。

安装顺序：

1. 阅读“01-电脑端安装说明.txt”，在自己的电脑上安装和启动服务。
2. 阅读“02-手机端安装说明.txt”，从官方渠道安装 Tailscale，再安装 Codex 私人端 APK。
3. 把自己电脑生成的“手机连接地址.txt”中的两个地址填入手机 App。

重要：手机端能发送指令，并能批准电脑上的命令执行和文件修改。只允许本人设备连接，确认内容后再点“允许”。
