Codex 私人端 - 电脑端安装

系统要求：Windows 10/11 64 位。

一、配置自己的 Codex/API

1. 在自己的电脑安装并打开 Codex 桌面端。
2. 按自己的日常方式配置自己的 API 地址、API Key 和模型。
3. 先在电脑端发送一条消息，确认 API 能正常使用。
4. 不要将 API Key 发给其他人，也不要写入本安装包。

二、安装独立电脑端

1. 解压整个安装包，不要直接在 ZIP 中运行。
2. 进入“host”文件夹。
3. 双击“1-安装电脑端.cmd”，Windows 询问管理员权限时点“是”。
4. 脚本会检查或安装 Node.js 和 Tailscale，并寻找本机 Codex 可执行文件。
5. Tailscale 打开后，用你自己的账号登录。不要加入他人、管理员或公司的 Tailnet。
6. 安装成功后，“host”文件夹会生成“手机连接地址.txt”。

三、以后使用

1. 保持电脑开机、联网，并保持 Tailscale 在线。
2. 电脑重启后，双击“2-启动独立手机端.cmd”。
3. 手机和电脑必须使用同一个人的 Tailscale 网络。
4. 不需要 USB，Wi-Fi 或移动网络都可以使用。

四、常见问题

- 提示找不到 Codex：先安装或更新 Codex 桌面端，并重新运行安装脚本。
- Tailscale 未连接：打开 Tailscale，登录自己的账号，再运行启动脚本。
- 电脑 IP 或账号变更：重新运行启动脚本，再查看新的“手机连接地址.txt”。
- 新建任务时，必须填写自己电脑上真实存在的完整目录路径。
- API 登录无法使用：先回到电脑端确认同一账号/API 配置能够正常发送消息。
