Codex 私人端 - 手机端安装

一、安装 Tailscale

1. 从 https://tailscale.com/download/android 或手机应用商店安装官方 Tailscale。
2. 打开 Tailscale，登录和自己电脑端相同的账号。
3. 允许创建 VPN 连接，打开顶部开关，确认显示 Connected。
4. 在设备列表中确认能看到自己的 Windows 电脑。
5. 不要加入他人、管理员或公司的共享 Tailnet。

二、安装 Codex 私人端

1. 安装“android\Codex私人端.apk”。如系统阻止安装，只对本次使用的文件管理器临时允许“安装未知应用”，安装完成后关闭该权限。
2. 打开 App，点顶部“设置”。
3. 打开自己电脑的“host\手机连接地址.txt”。
4. 将文件中的“当前入口”和“自动发现地址”分别填入 App。
5. 点“保存并打开”，显示“已连接”即可使用。

三、注意

- 手机 App 不保存 API Key，使用的是你自己电脑上的 Codex/API 配置。
- 发送任务会使用你自己的 API 额度。
- 你只能看到自己电脑上的任务，但同一 Tailnet 中的其他受信任设备可能访问该服务。
- 不要把“手机连接地址.txt”和 Tailscale 账号共享给无关人员。
- 手机端能请求执行命令和修改文件；不确定影响时不要点“允许”。

四、连不上时

1. 确认手机和电脑的 Tailscale 都显示 Connected。
2. 确认手机能在 Tailscale 设备列表看到自己的电脑。
3. 在电脑重新运行“2-启动独立手机端.cmd”。
4. 在手机 App 点“重连”，并核对电脑生成的两个地址。
